# Lion identity studies

**Selected mascot: [Zoey the XUI Lion](zoey.md).**
The brand kit contains the canonical H02 design, status palettes, and production SVG, PNG, and ICO assets.
The studies below remain as design history.

These drafts explore a lion mascot for XUI.
The broad collection contains 120 concepts, including the original twelve.
The focused Solar revision adds six silhouettes in seven palettes.
Solar round three adds a broader study of 48 shape-and-proportion combinations.
D2 style explorations reinterpret the selected fan design in 24 visual styles.
The Softling study explores fuller manes and four treatments for the joins between segments.

Every concept shows a lion head from the front.
Only Zoey is the selected application identity.

[Open the comparison gallery](index.html) in a browser.
The gallery works as a local file without a server or external dependencies.
It includes light and dark backgrounds, small icon previews, and a temporary shortlist.
The contact-sheet view shows more concepts at once.
Search supports concept numbers, names, and style descriptions.
The collection filter separates the original twelve from three new groups.
Shortlist selections last until the page reloads.

## Happy High Crown

[Open the final-touch comparison](high-crown-finish/index.html) for two updates to the selected [C03 / High Crown](cloud-crown/c03-high-crown.svg).
The original C03 remains unchanged.

- [H01 / Happy eyes](high-crown-finish/h01-happy.svg): Upward-arched closed eyes replace the sleepy eye curves. Nothing else changes.
- [H02 / Happy eyes and outlines](high-crown-finish/h02-happy-outlined.svg): The same happy eyes, with a brown face outline and darker color-matched mane borders.

The mane border follows only the perimeter, including the exposed lower ends.
It does not trace the joins between colors.
The border sits inside the original mane silhouette.
One continuous border joins the corners without notches where the colors meet.
Each border color uses 68 percent of the corresponding Enamel RGB channels.
The face and ears have an outline in the existing brown feature color.
The comparison includes the original C03, both updates, dark artboards, and small previews.

The [finish generator](../../../tools/branding/generate_high_crown_finish.py) reads the original C03 and preserves its geometry.

## Softling fuller manes

[Open the Softling comparison](softling/index.html) for sixteen mane variations.
The selected source is [S06 / Softling](solar-d2-styles/06-softling.svg).
Every variation keeps its face paths, size, position, expression, and pastel palette unchanged.
Only the mane changes.

Four outer contours each have four join treatments.
The narrow-gap versions use real transparent channels, not white paint.
The touching-color versions have a continuous mane without gaps or divider lines.
The fine-divider versions add thin brown lines without holes.
The wavy-join versions use shared S-shaped color boundaries.

- Plush fan: [M01 / narrow gaps](softling/m01-plush-narrow.svg), [M02 / touching colors](softling/m02-plush-joined.svg), [M03 / fine dividers](softling/m03-plush-lined.svg), [M04 / wavy joins](softling/m04-plush-wavy.svg).
- Round halo: [M05 / narrow gaps](softling/m05-halo-narrow.svg), [M06 / touching colors](softling/m06-halo-joined.svg), [M07 / fine dividers](softling/m07-halo-lined.svg), [M08 / wavy joins](softling/m08-halo-wavy.svg).
- Cloud crown: [M09 / narrow gaps](softling/m09-cloud-narrow.svg), [M10 / touching colors](softling/m10-cloud-joined.svg), [M11 / fine dividers](softling/m11-cloud-lined.svg), [M12 / wavy joins](softling/m12-cloud-wavy.svg).
- Rolling wave: [M13 / narrow gaps](softling/m13-wave-narrow.svg), [M14 / touching colors](softling/m14-wave-joined.svg), [M15 / fine dividers](softling/m15-wave-lined.svg), [M16 / wavy joins](softling/m16-wave-wavy.svg).

All variations keep six colors and a clear chin.
The original Softling remains available beside each variation in the comparison page.
Dark artboards show the difference between transparent gaps and continuous color.
These are geometry drafts, not a new set of status recolors.

The [Softling generator](../../../tools/branding/generate_softling.py) defines shared boundaries so adjacent segments meet exactly.
The continuous versions include clipped overpaint and a backing shape to prevent transparent rendering cracks along the joins.
The source face is copied without modification.

## Solar round two

[Open the Solar comparison page](solar/index.html) for six-segment mane revisions.
Each revision preserves the original Solar face paths, proportions, and expression.
The mane sits above and beside the head, with no mane below the chin.
The segments have curved edges and transparent gaps.
The whole head moves down slightly within the canvas to center the shorter silhouette.

- [A / Soft arc](solar/a-soft-arc-rainbow.svg): Balanced waves and short side locks.
- [B / High crown](solar/b-high-crown-rainbow.svg): A higher crown and the shortest lower locks.
- [C / Round petals](solar/c-round-petals-rainbow.svg): A plumper, softer silhouette.
- [D / Tidal wave](solar/d-tidal-wave-rainbow.svg): More pronounced ripples.
- [E / Close crop](solar/e-close-crop-rainbow.svg): A narrow, compact mane.
- [F / Swept locks](solar/f-swept-locks-rainbow.svg): Curved shoulders that sweep upward.

Rainbow is the canonical palette for this revision.
It retains the original golden face.
Each status version uses a single hue with light and dark tones, not a flat one-ink treatment.
The face geometry and six mane segments remain identical across palettes.

## Draft scope

Each SVG has a transparent background and a `256 256` view box.
The files contain editable vector shapes, accessible titles, and descriptions.
They use no fonts, embedded raster images, scripts, or external resources.
The gallery pairs each head with system-font XUI text, not a finished wordmark.
The three `concepts-*.js` files supply the new gallery entries.
These data files must remain beside `index.html`.

The small previews expose detail loss rather than promise production-ready icons.
Fine strokes in Monoline, Deco, and Woodcut need simplification for small sizes.
The dark preview exposes contrast limits without recoloring the artwork.
These concepts are original drawings, not trademark-clearance results.

For the next revision, identify concepts by number or name.
A revision can combine one mane, another expression, and a different palette.
